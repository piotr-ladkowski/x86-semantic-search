Evidence

A page being found is not the same as it being right. For every sentence, table row and code listing on a page we record which sentences of the reference documents it was derived from, so you can read the two side by side.

Open a page’s evidence from the Source box on its page. The statements are listed in order; the sources they rest on sit under them with the cited sentences highlighted. A statement is in one of these states:

  • Traced: a person or an AI read the cited sentences and judged that they support it (an exact match of an opcode and instruction form in an SDM table is also counted).
  • Derived: not stated in a source, but follows from sentences that are cited; the note says how.
  • Checked by running it: a program in the repository assembles and runs the example.
  • Illustrative and advice: an invented example, or a recommendation, with nothing to quote.
  • Cited to an outside source: such as a compiler manual; the note names it, but it is not one of the documents we can look sentences up in.
  • Suggested: found by text similarity and not confirmed by anyone. Treat as a hint.
  • Not yet checked: nothing recorded yet.

The reference documents are copyrighted, so this project stores only pointers (document, page, a fingerprint of the sentence), never their text. The passages appear on a machine that has its own copy of each document; the pointers work everywhere.
